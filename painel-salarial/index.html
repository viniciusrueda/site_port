Metodologia: valores de admissão CLT declarados ao Novo CAGED (jul/2024–jun/2025), nacional. Piso e teto calculados como percentil 5 e 95 (não mínimo/máximo), para reduzir o efeito de erros de digitação no dado bruto. Ocupações com menos de 30 admissões no período foram descartadas por baixa confiabilidade estatística.

Pipeline: extração via consultas SQL agregadas no Google BigQuery (dataset público do CAGED/MTE) → tratamento e compactação dos dados em Python → arquivos JSON estáticos consumidos direto pelo navegador, sem servidor ou banco de dados ativo.
